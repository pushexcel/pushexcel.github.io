Mengenal editor VBA

Editor VBA adalah tempat menulis, membaca, dan mengubah kode macro. Buka dengan Alt+F11.

Intinya

Macro tersimpan sebagai kode. Editor VBA adalah buku catatan untuk kode itu.

Bayangkan begini

Bayangkan macro itu resep. Kamu merekamnya seperti memotret masakan. Editor VBA seperti buku resep tempat kamu bisa membaca langkah-langkahnya dan mengubahnya.

Buka versi interaktif
Sub NamaMacro()
    ' kode di sini
End Sub

Langkah praktik

  1. Tekan Alt+F11 untuk membuka editor.
  2. Klik Insert lalu Module untuk membuat lembar kode kosong.
  3. Tulis kode di antara baris Sub dan End Sub.
  4. Tekan F5 untuk menjalankan, atau jalankan lewat Developer lalu Macros.
  5. Contoh: Range("A1").Value = "Halo" mengisi kotak A1 dengan tulisan Halo.

Tips

Tanda apostrof (') membuat sisa baris menjadi komentar. Komentar diabaikan saat kode berjalan.

Kapan dipakai

Kamu membuka editor VBA saat ingin melihat atau mengubah kode macro. Misalnya guru yang merekam macro format nilai lalu ingin mengganti warna latarnya tanpa merekam ulang. Atau staf gudang yang ingin menulis macro kecil sendiri untuk mengisi tanggal otomatis di sebuah kotak. Di sinilah kode disimpan dan dirapikan, jadi kamu butuh tahu letak jendelanya dan cara menjalankan kode dari sana.

Contoh

Sub SapaKelas()
    ' ubah tulisan di bawah sesuai kebutuhan
    Range("B2").Value = "Selamat belajar"
End Sub

Siapkan lembar kosong. Tekan Alt+F11, klik Insert lalu Module, lalu ketik kode di atas di jendela kosong. Baris Sub SapaKelas() memberi nama prosedur. Baris yang diawali apostrof adalah komentar. Excel mengabaikannya, dan kamu memakainya sebagai catatan untuk dirimu sendiri. Baris Range("B2").Value = "Selamat belajar" menaruh tulisan itu di kotak B2. Baris End Sub menutup prosedur. Klik di antara baris Sub dan End Sub, tekan F5, lalu kembali ke lembar kerja. Kotak B2 kini berisi Selamat belajar. Kalau B2 sudah ada isinya, tulisan lama tertimpa, jadi pilih kotak yang kosong. Hapus komentarnya kalau sudah tidak perlu, tanpa mengganggu kode lain.

Kesalahan yang sering terjadi

  • Alt+F11 tidak membuka apa-apa

    Penyebab: Pada sebagian laptop tombol F1 sampai F12 harus ditekan bersama tombol Fn.

    Solusi: Coba Alt+Fn+F11, atau buka lewat tab Developer lalu tombol Visual Basic.

  • Muncul pesan Compile error: Expected: End Sub

    Penyebab: Ada Sub yang belum ditutup dengan End Sub.

    Solusi: Tambahkan baris End Sub di akhir prosedur, lalu coba jalankan lagi.

  • Menekan F5 malah memunculkan daftar macro

    Penyebab: Kursor tidak berada di dalam sebuah Sub, jadi editor tidak tahu mana yang dijalankan.

    Solusi: Klik di antara baris Sub dan End Sub, lalu tekan F5 lagi.

  • Sebaris kode berubah menjadi merah

    Penyebab: Ada salah tulis, misalnya tanda kutip atau kurung yang tidak berpasangan.

    Solusi: Periksa baris merah itu. Pastikan setiap kutip dan kurung buka punya pasangan penutup.

Jangan tertukar

Bar rumus dan editor VBA sama-sama tempat mengetik, tetapi fungsinya jauh berbeda. Di bar rumus kamu menulis rumus untuk satu kotak, dan hasilnya dihitung ulang otomatis. Di editor VBA kamu menulis prosedur, yaitu urutan perintah yang baru berjalan saat kamu menjalankannya. Prosedur bisa mengubah banyak kotak, lembar, bahkan tampilan sekaligus, sesuatu yang tidak bisa dilakukan satu rumus biasa.

Tanya jawab

Apa itu Module dan mengapa saya harus membuatnya?

Module adalah lembar kosong di editor VBA tempat kamu menaruh kode. Tanpa module, kamu tidak punya tempat menulis prosedur umum. Satu module boleh berisi banyak Sub. Kamu membuatnya lewat Insert lalu Module, dan bisa memberi nama yang jelas di jendela Properties kalau mau mengelompokkan kode.

Apakah kode yang saya tulis ikut tersimpan di file?

Ya, kode ikut tersimpan di workbook yang sedang aktif. Tetapi file harus disimpan dalam format .xlsm. Kalau kamu menyimpan sebagai .xlsx, kode tidak dibawa. Jadi sebelum menutup Excel, pastikan format filenya sudah benar supaya hasil kerjamu di editor tidak hilang.

Apakah mengubah kode bisa merusak file Excel saya?

Mengedit kode tidak merusak struktur file. Namun kode yang salah bisa mengubah isi lembar saat dijalankan, misalnya menimpa kotak yang sudah terisi. Biasakan menyimpan salinan file sebelum mencoba kode baru, dan uji pertama kali di lembar latihan yang isinya tidak penting.

Ringkasan

Editor VBA, dibuka dengan Alt+F11, adalah tempat kode macro ditulis. Buat Module, tulis kode di antara Sub dan End Sub, lalu jalankan dengan F5 sambil kursor berada di dalam Sub.
