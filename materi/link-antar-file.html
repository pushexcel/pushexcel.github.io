Menghubungkan data antar sheet dan antar file

Sebuah rumus bisa mengambil angka dari sheet lain atau bahkan dari file lain. Kalau angka sumbernya berubah, hasilnya ikut berubah.

Intinya

Rumus yang menunjuk ke sheet atau file lain membuat datamu saling tersambung.

Bayangkan begini

Bayangkan kamu menulis di buku catatan, "Harga bensin: lihat papan di SPBU." Kamu tidak menyalin harganya, hanya menunjuk. Saat harga di papan berganti, catatanmu ikut benar. Link antar file bekerja begitu.

Buka versi interaktif
=Sheet2!B5   atau   ='[Data.xlsx]Sheet1'!$B$5

Penjelasan untuk pemula

Bayangkan seorang bendahara RT punya dua buku. Buku pertama mencatat iuran tiap bulan. Buku kedua adalah laporan tahunan. Setiap akhir bulan, ia menyalin total dari buku pertama ke buku kedua. Lalu datang iuran susulan, dan total di buku pertama berubah. Angka di buku kedua masih yang lama. Kalau lupa menyalin ulang, laporan tidak cocok dengan catatan aslinya. Excel punya jalan keluar: jangan menyalin angkanya, cukup tunjuk letaknya. Rumus yang menunjuk ke kotak lain disebut link, atau tautan. Kamu menulis alamat kotak sumber di dalam rumus. Excel lalu mengambil isi kotak itu setiap kali dibutuhkan. Ada dua jenis tujuan. Pertama, sheet lain di file yang sama. Sheet adalah lembar kerja, yaitu halaman di dalam satu file, yang namanya tampak di tab bagian bawah layar. Kedua, file lain. Alamat pada tujuan ini lebih panjang karena harus menyebut nama file juga. Kamu tidak perlu menghafal bentuknya. Ketik tanda =, lalu klik kotak yang kamu mau, dan Excel menuliskan alamat lengkapnya. Tanda seru ! di dalam alamat memisahkan nama sheet dari nama kotak. Tanda kurung siku [ ] membungkus nama file. Hasilnya, angka cukup diketik sekali, di satu tempat. Tempat lain hanya mengambilnya. Halaman ini membimbingmu membuat link dari lembar kosong, lalu memeriksa bahwa sambungannya benar.

Istilah penting

Link (tautan)
Rumus yang mengambil isi kotak dari sheet atau file lain. Angkanya tidak disalin, jadi selalu mengikuti perubahan di sumbernya.
File sumber
File Excel tempat angka aslinya disimpan. File ini yang kamu ubah kalau angka perlu diperbarui, bukan file yang mengambilnya.
File tujuan
File yang berisi rumus link dan menampilkan angka kiriman dari file sumber. Biasanya berupa ringkasan atau laporan.
Sheet
Satu lembar kerja di dalam file Excel. Namanya tampak pada tab di bagian bawah layar, misalnya Sheet1 atau Januari.
Tanda seru (!)
Tanda pemisah di dalam alamat. Bagian sebelum tanda ini adalah nama sheet, bagian sesudahnya adalah alamat kotak, misalnya Januari!C7.
Edit Links
Perintah di tab Data yang menampilkan semua file sumber yang dipakai file ini. Dari sini kamu bisa memperbarui, mengganti lokasi, atau memutus link.
Break Link
Tombol untuk memutus sambungan ke file sumber. Rumus diganti angka terakhirnya, sehingga angka tidak lagi berubah mengikuti sumber.

Langkah praktik

  1. Buka dua file Excel. Klik View lalu View Side by Side supaya keduanya tampil berdampingan.
  2. Di file tujuan, ketik tanda = lalu klik kotak yang mau diambil di file sumber.
  3. Tekan Enter. Excel menuliskan alamat lengkapnya untuk kamu.
  4. Kalau file sumber pernah dipindah, buka Data lalu Edit Links untuk memperbaiki sambungannya.

Tips

Jangan ganti nama atau memindahkan file sumber tanpa memperbarui link. Kalau tidak, rumusnya kehilangan jalan menuju datanya.

Panduan langkah demi langkah

  1. Siapkan dua tempat yang jelas

    Tentukan dulu mana sumber dan mana tujuan. Di file sumber, simpan angka yang mau diambil, misalnya total di kotak C7. Beri nama sheet yang jelas, misalnya Januari. Simpan file itu dengan Ctrl+S. Nama yang rapi sekarang akan memudahkanmu membaca rumus nanti. Simpan juga rencanamu di kepala: file ini yang akan dibaca, file lain yang akan menunggu.

  2. Buka file tujuan di jendela terpisah

    Buka file tujuan dan file sumber sekaligus. Kalau layarmu kecil, klik View lalu View Side by Side supaya keduanya berdampingan. Kamu bisa berpindah dengan Alt+Tab. Pastikan kamu tahu jendela mana yang sedang aktif, karena judul file tampak di bagian atas. Setelah dua jendela siap, kamu bisa berpindah-pindah tanpa tersesat dan tanpa menutup apa pun.

  3. Klik kotak tempat angka akan tampil

    Di file tujuan, klik satu kotak kosong, misalnya B2 di sheet Rekap. Kotak ini akan menampilkan angka kiriman. Pilih kotak yang bersih supaya tidak menimpa isi lama. Lihat Name Box di kiri atas untuk memastikan alamat kotak yang kamu klik. Kalau kamu sudah membuat judul kolom, kotak ini biasanya terletak tepat di bawahnya.

  4. Ketik tanda sama dengan

    Ketik = pada kotak itu. Tanda ini memberi tahu Excel bahwa kamu sedang menulis rumus, bukan teks. Kotak masuk ke mode mengetik, dan tulisan yang sama juga tampak di Formula Bar, yaitu baris panjang di atas lembar kerja. Jangan tekan Enter dulu. Tanda sama dengan wajib ada di awal, karena tanpa tanda itu Excel hanya menyimpan tulisan biasa.

  5. Klik kotak sumber di sheet atau file lain

    Klik tab sheet Januari di file yang sama, atau pindah ke jendela file sumber. Lalu klik kotak C7. Kotak itu dikelilingi garis putus-putus. Di Formula Bar, alamatnya mulai tertulis, kira-kira =Januari!C7. Untuk file lain, nama file dalam kurung siku ikut muncul. Klik, bukan ketik: cara ini mencegah salah huruf pada nama sheet atau nama file.

  6. Tekan Enter dan baca hasilnya

    Tekan Enter. Excel kembali ke file tujuan, dan kotak menampilkan angka dari C7. Klik kotak itu sekali lagi, lalu lihat Formula Bar. Rumus yang terbaca adalah alamat, bukan angka. Itu tanda bahwa kotak tersambung. Bandingkan angkanya dengan sumber supaya kamu yakin tidak salah klik. Kalau yang tampil justru tulisan rumus, cek apakah kotaknya berformat Text lalu ulangi langkahnya.

  7. Uji dengan mengubah angka sumber

    Pergi ke file sumber, ganti angka di C7 dengan angka lain, lalu kembali ke file tujuan. Kalau kedua file terbuka, angkanya ikut berubah. Ujian ini penting karena membuktikan link hidup, bukan hasil salinan. Kembalikan angka asli setelah uji selesai. Setelah angka asli kembali, pastikan kedua file menunjukkan angka yang sama lagi seperti sebelumnya.

  8. Salin link ke kotak lain bila perlu

    Mau mengambil banyak bulan? Tarik Fill handle, yaitu kotak kecil di sudut kanan bawah kotak aktif, ke bawah. Perhatikan alamatnya. Link ke sheet lain dalam satu file ikut bergeser, sedangkan alamat bertanda dolar seperti $C$7 tidak bergeser. Edit kotak dengan F2 kalau perlu. Setelah ditarik, klik beberapa kotak hasil dan periksa apakah alamat yang tertulis memang yang kamu maksud.

  9. Simpan kedua file di tempat tetap

    Simpan file tujuan dengan Ctrl+S. Letakkan kedua file di folder yang akan kamu pakai terus, dan jangan ganti namanya sembarangan. Excel mengingat lokasi file sumber di dalam rumus. Kalau lokasi berubah, sambungan putus dan kamu harus memperbaikinya lewat Data lalu Edit Links. Kebiasaan kecil ini menjaga laporanmu tetap terbuka dengan benar di hari-hari berikutnya.

  10. Buka ulang dan periksa peringatan

    Tutup lalu buka file tujuan lagi. Excel mungkin menampilkan peringatan keamanan soal link. Kalau kamu mengenal file sumbernya, izinkan pembaruan. Lalu bandingkan kembali angka tujuan dengan sumber. Kalau cocok, sambunganmu sudah benar dan siap dipakai. Kalau Excel menanyakan pembaruan, baca dulu nama file yang disebut sebelum menekan tombol apa pun.

Kapan dipakai

Link antar sheet dan antar file menghindarkanmu dari menyalin angka berulang kali. Bendahara sekolah punya satu file rekap per bulan, lalu satu file ringkasan tahunan yang mengambil total dari masing-masing file itu. Pemilik toko menyimpan harga barang di satu sheet dan memakainya di sheet nota tanpa mengetik ulang. Saat harga atau total berubah, angka di tempat lain ikut diperbarui, jadi kamu tidak perlu mencari dan mengganti satu per satu.

Contoh

Bayangkan file Data.xlsx berisi sheet bernama Sheet1 dengan total bulanan di kotak B5. Kamu membuka file ringkasan, mengklik kotak kosong, mengetik =, lalu berpindah ke file Data dan mengklik kotak B5. Setelah Enter, Excel menuliskan alamat lengkapnya, kira-kira ='[Data.xlsx]Sheet1'!$B$5. Angka dari file sumber kini tampil di file ringkasan. Kalau di file Data total itu diganti, angka di ringkasan ikut berubah. Untuk link ke sheet lain dalam file yang sama, alamatnya lebih pendek, seperti =Sheet2!B5. Pastikan juga file Data tetap berada di folder yang sama. Kalau rumus disalin ke bawah, alamat bertanda dolar tidak bergeser.

Contoh kasus lanjutan

Kasus 1: Rekap iuran RT dari tiga sheet bulanan

Bu Ratna, bendahara RT 05, memegang satu file dengan sheet Januari, Februari, dan Maret. Tiap sheet mencatat iuran per blok rumah. Ia membuat sheet Rekap yang hanya mengambil total tiap bulan, supaya laporan triwulan tidak perlu diketik ulang. Di bawah ini sheet Januari, dengan jumlah rumah yang membayar dan iuran per blok. Tiap bulan, ia hanya ingin satu angka total yang ikut berubah.

Di sheet Januari, Bu Ratna menjumlahkan iuran empat blok di C6. Mesin menghitung 1260000. Jumlah rumah yang membayar di B6 adalah 42. Kedua angka ini adalah sumber. Di sheet Rekap, ia mengklik kotak kosong, mengetik =, pindah ke tab Januari, lalu mengklik C6 dan menekan Enter. Rumus yang tertulis kira-kira =Januari!C6, dan hasilnya tampil 1260000 juga. Ia mengulang untuk Februari dan Maret dengan klik kotak total masing-masing. Kalau nanti blok D membayar iuran susulan, C5 berubah, C6 ikut berubah, lalu Rekap otomatis mengikuti. Ia tidak mengetik ulang apa pun, jadi risiko angka tidak cocok hampir hilang.

Kasus 2: Nota warung yang mengambil harga dari file Harga

Pak Hendra punya warung kelontong. Harga barang ia simpan di file Harga.xlsx, sheet Daftar, supaya cukup diubah di satu tempat. File Nota.xlsx mengambil harga dari sana, lalu mengalikannya dengan jumlah beli. Tabel di bawah adalah isi file Nota. Kolom Harga berisi link ke file Harga, sedangkan Jumlah diketik langsung. Ia ingin harga cukup diubah sekali.

Telur: 2200 dikali 12 menjadi 26400. Minyak 16500 dikali 2 menjadi 33000, dan kopi 1500 dikali 20 menjadi 30000. Rumus =SUM(D2:D5) menjumlahkan keempat subtotal dan hasilnya 124400. Hal pentingnya ada pada Pak Hendra: kalau harga minyak naik, ia membuka Harga.xlsx dan mengganti satu kotak saja. Nota yang dibuka sesudahnya mengambil harga baru. Nota lama yang sudah dicetak tidak berubah, jadi simpan salinannya kalau perlu bukti.

Latihan mandiri

Coba kerjakan sendiri di Excel dulu, baru cocokkan dengan jawabannya.

Latihan 1

Di file baru, isi sheet Sheet1 pada kotak B5 dengan angka 250. Pindah ke Sheet2, lalu buat rumus di kotak A1 yang mengambil isi B5 dari Sheet1 tanpa mengetik angkanya. Ubah B5 menjadi 300, lalu lihat A1.

Petunjuk: Ketik tanda sama dengan di Sheet2, klik tab Sheet1, lalu klik B5 dan tekan Enter. Jangan mengetik angkanya.

Lihat jawaban

Rumus di A1 pada Sheet2 berbunyi =Sheet1!B5 dan awalnya menampilkan 250. Setelah B5 diganti 300, A1 ikut menjadi 300. Itu membuktikan kotak tersambung. Kalau A1 tetap 250, berarti kamu menyalin angkanya, bukan membuat link, jadi ulangi dengan klik kotak.

Latihan 2

Sheet Data punya angka penjualan mingguan di B2:B5, seperti pada tabel. Buat sheet Ringkasan yang menampilkan jumlahnya dalam satu kotak. Lalu ganti salah satu angka di Data dan periksa apakah Ringkasan ikut berubah.

Petunjuk: Di Ringkasan, ketik =SUM(, klik tab Data, sorot B2:B5 dengan mouse, ketik ), lalu tekan Enter.

Lihat jawaban

Rumus: =SUM(B2:B5). Hasil: 500.

Di sheet Data, =SUM(B2:B5) memberi 500 karena 120 ditambah 150, 90, dan 140. Rumus di Ringkasan bentuknya =SUM(Data!B2:B5) dan hasilnya sama. Kalau minggu 3 diganti 100, Ringkasan menjadi 510. Alamat sheet ikut masuk ke dalam rumus.

Latihan 3

Kamu punya sheet bernama Data Mei dengan angka di B5. Tulis rumus di sheet lain yang mengambil B5 itu, lalu jelaskan kenapa nama sheet itu perlu tanda petik. Setelah itu, ubah nama file sumber dan amati apa yang terjadi pada link.

Petunjuk: Nama yang berspasi dibungkus tanda petik satu. Untuk bagian akhir, pakai file kedua, lalu cek Data lalu Edit Links.

Lihat jawaban

Rumusnya ='Data Mei'!B5. Tanda petik perlu karena spasi akan membuat Excel bingung di mana nama sheet berakhir. Kalau file sumber diganti namanya saat tertutup, Excel gagal menemukannya saat memperbarui. Buka Data lalu Edit Links, pilih link itu, dan klik Change Source untuk menunjuk nama baru.

Tips lanjutan

  • Biarkan Excel yang mengetik alamatnya

    Mengetik alamat lengkap dengan tangan mudah salah, terutama tanda kurung siku dan tanda petik. Lebih aman mengklik kotak sumbernya. Kalau file sumber terbuka, Excel menulis nama file, nama sheet, dan alamat kotak dengan benar. Kamu cukup memeriksa hasilnya. Cara ini juga menolongmu saat nama sheet berspasi, karena tanda petik ditambahkan otomatis.

  • Pakai nama sheet yang pendek dan polos

    Nama sheet seperti Jan, Feb, dan Mar membuat rumus mudah dibaca. Nama berspasi memaksa tanda petik, dan nama panjang membuat rumus sulit dilihat di Formula Bar. Ganti nama dengan klik dua kali pada tab sheet. Hal ini sebaiknya dilakukan sebelum membuat link. Nama pendek membuat orang lain yang membuka filemu cepat paham.

  • Kumpulkan file yang saling terhubung dalam satu folder

    Taruh file sumber dan file tujuan di folder yang sama, lalu beri nama folder yang jelas. Saat dipindah ke komputer lain, pindahkan seluruh folder. Ini mengurangi risiko link putus. Jangan lupa memberi tahu rekan kerja bahwa file saling bergantung. Satu folder juga memudahkan pencadangan, karena semua yang saling bergantung ikut tersalin.

  • Pakai Edit Links untuk pemeriksaan berkala

    Buka Data lalu Edit Links untuk melihat daftar file sumber yang dipakai. Dari sana kamu bisa memperbarui nilai, mengganti lokasi lewat Change Source, atau memutus lewat Break Link. Biasakan mengeceknya sebelum mengirim file ke orang lain. Pemeriksaan ini hanya perlu beberapa detik dan sering menyelamatkan laporan dari angka lama.

  • Putus link sebelum mengirim laporan final

    Kalau laporan sudah final dan akan dikirim ke pihak lain, pertimbangkan memutus link dengan Break Link. Angka tetap tampil, tetapi tidak lagi meminta file sumber. Simpan versi bertaut di folder sendiri sebagai cadangan, kalau suatu saat kamu perlu memperbaruinya. Beri nama file yang jelas.

Kesalahan yang sering terjadi

  • Muncul peringatan bahwa pembaruan link otomatis dimatikan

    Penyebab: Excel menahan link ke file lain demi keamanan sampai kamu mengizinkannya.

    Solusi: Klik Enable Content pada baris peringatan kalau kamu mengenal dan memercayai file sumbernya.

  • Rumus menghasilkan #REF!

    Penyebab: Sheet atau kotak yang dituju sudah dihapus, sehingga rumus kehilangan sasarannya.

    Solusi: Bila baru terjadi, tekan Ctrl+Z. Kalau sudah disimpan, tulis ulang rumus dan arahkan ke kotak yang benar.

  • Excel mengaku tidak bisa memperbarui link setelah file sumber dipindah

    Penyebab: Link menyimpan lokasi lama file sumber. Setelah dipindah atau diganti nama, lokasi itu tidak ada lagi.

    Solusi: Buka Data lalu Edit Links, pilih link yang bermasalah, dan arahkan ke lokasi file yang baru lewat Change Source.

  • Rumus menampilkan nama sheet dengan tanda petik atau error karena nama sheet berspasi

    Penyebab: Nama sheet yang mengandung spasi harus diapit tanda petik satu di dalam rumus.

    Solusi: Biarkan Excel yang menulisnya lewat klik kotak. Kalau mengetik sendiri, tulis seperti ='Data Bulan 1'!B5.

Jangan tertukar

Link sering dibandingkan dengan menyalin angka dengan Paste Special Values. Salinan Values membekukan angka pada saat ditempel dan tidak berubah lagi, seperti foto. Link seperti jendela: selalu menampilkan isi terbaru dari sumbernya. Pakai Values kalau angka sudah final atau file akan dikirim. Pakai link kalau angka sumber masih bisa berubah dan kamu ingin laporannya mengikuti.

Cek cepat sebelum selesai

  • Rumus di file tujuan menampilkan alamat kotak sumber, bukan angka yang diketik langsung.
  • Angka di file tujuan sama dengan angka di kotak sumber yang kamu tunjuk.
  • Setelah angka sumber diubah, angka di file tujuan ikut berubah, lalu kamu kembalikan.
  • Nama sheet berspasi sudah dibungkus tanda petik satu di dalam rumus.
  • File sumber dan file tujuan tersimpan di folder yang akan dipakai terus.
  • Data lalu Edit Links hanya menampilkan file sumber yang memang kamu kenal.
  • Untuk laporan yang akan dikirim keluar, kamu sudah memutuskan memakai link atau angka tetap.

Tanya jawab

Apakah file sumber harus terbuka supaya link berfungsi?

Tidak harus. Kalau file sumber tertutup, rumus memakai angka terakhir yang tersimpan, dan Excel menawarkan pembaruan ketika file ringkasan dibuka. Namun saat kamu mengedit rumus link-nya, lebih mudah jika kedua file terbuka karena alamat lengkapnya bisa dibuat otomatis lewat klik.

Bagaimana kalau file ringkasan akan dikirim ke orang lain?

Link menunjuk ke lokasi file di komputermu, jadi di komputer lain sumbernya mungkin tidak ditemukan. Kirim kedua file bersama, atau ubah link menjadi angka tetap lewat Edit Links dengan tombol Break Link. Setelah diputus, angkanya tetap tampil tetapi tidak lagi mengikuti file sumber.

Apa arti tanda dolar pada alamat seperti $B$5?

Tanda dolar mengunci alamat supaya tidak bergeser ketika rumus disalin ke kotak lain. Pada link antar file, Excel menuliskannya otomatis sehingga rumus selalu menunjuk persis ke kotak yang kamu klik. Tanda ini tidak berhubungan dengan mata uang dan tidak memengaruhi angka yang ditampilkan.

Ringkasan

Link antar sheet dan file membuat rumus mengambil angka langsung dari sumbernya, sehingga hasil selalu mengikuti data terbaru. Jaga file sumber tetap di tempatnya, dan perbarui lewat Edit Links bila lokasinya berubah.
