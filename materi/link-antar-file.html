Menghubungkan data antar sheet dan antar file

Sebuah rumus bisa mengambil angka dari sheet lain atau bahkan dari file lain. Kalau angka sumbernya berubah, hasilnya ikut berubah.

Intinya

Rumus yang menunjuk ke sheet atau file lain membuat datamu saling tersambung.

Bayangkan begini

Bayangkan kamu menulis di buku catatan, "Harga bensin: lihat papan di SPBU." Kamu tidak menyalin harganya, hanya menunjuk. Saat harga di papan berganti, catatanmu ikut benar. Link antar file bekerja begitu.

Coba langsung di browserLembar kerja mini, kuis, dan tanda selesai.

Buka versi interaktif
=Sheet2!B5   atau   ='[Data.xlsx]Sheet1'!$B$5

Langkah praktik

  1. Buka dua file Excel. Klik View lalu View Side by Side supaya keduanya tampil berdampingan.
  2. Di file tujuan, ketik tanda = lalu klik kotak yang mau diambil di file sumber.
  3. Tekan Enter. Excel menuliskan alamat lengkapnya untuk kamu.
  4. Kalau file sumber pernah dipindah, buka Data lalu Edit Links untuk memperbaiki sambungannya.

Tips

Jangan ganti nama atau memindahkan file sumber tanpa memperbarui link. Kalau tidak, rumusnya kehilangan jalan menuju datanya.

Kapan dipakai

Link antar sheet dan antar file menghindarkanmu dari menyalin angka berulang kali. Bendahara sekolah punya satu file rekap per bulan, lalu satu file ringkasan tahunan yang mengambil total dari masing-masing file itu. Pemilik toko menyimpan harga barang di satu sheet dan memakainya di sheet nota tanpa mengetik ulang. Saat harga atau total berubah, angka di tempat lain ikut diperbarui, jadi kamu tidak perlu mencari dan mengganti satu per satu.

Contoh

Bayangkan file Data.xlsx berisi sheet bernama Sheet1 dengan total bulanan di kotak B5. Kamu membuka file ringkasan, mengklik kotak kosong, mengetik =, lalu berpindah ke file Data dan mengklik kotak B5. Setelah Enter, Excel menuliskan alamat lengkapnya, kira-kira ='[Data.xlsx]Sheet1'!$B$5. Angka dari file sumber kini tampil di file ringkasan. Kalau di file Data total itu diganti, angka di ringkasan ikut berubah. Untuk link ke sheet lain dalam file yang sama, alamatnya lebih pendek, seperti =Sheet2!B5. Pastikan juga file Data tetap berada di folder yang sama. Kalau rumus disalin ke bawah, alamat bertanda dolar tidak bergeser.

Kesalahan yang sering terjadi

  • Muncul peringatan bahwa pembaruan link otomatis dimatikan

    Penyebab: Excel menahan link ke file lain demi keamanan sampai kamu mengizinkannya.

    Solusi: Klik Enable Content pada baris peringatan kalau kamu mengenal dan memercayai file sumbernya.

  • Rumus menghasilkan #REF!

    Penyebab: Sheet atau kotak yang dituju sudah dihapus, sehingga rumus kehilangan sasarannya.

    Solusi: Bila baru terjadi, tekan Ctrl+Z. Kalau sudah disimpan, tulis ulang rumus dan arahkan ke kotak yang benar.

  • Excel mengaku tidak bisa memperbarui link setelah file sumber dipindah

    Penyebab: Link menyimpan lokasi lama file sumber. Setelah dipindah atau diganti nama, lokasi itu tidak ada lagi.

    Solusi: Buka Data lalu Edit Links, pilih link yang bermasalah, dan arahkan ke lokasi file yang baru lewat Change Source.

  • Rumus menampilkan nama sheet dengan tanda petik atau error karena nama sheet berspasi

    Penyebab: Nama sheet yang mengandung spasi harus diapit tanda petik satu di dalam rumus.

    Solusi: Biarkan Excel yang menulisnya lewat klik kotak. Kalau mengetik sendiri, tulis seperti ='Data Bulan 1'!B5.

Jangan tertukar

Link sering dibandingkan dengan menyalin angka dengan Paste Special Values. Salinan Values membekukan angka pada saat ditempel dan tidak berubah lagi, seperti foto. Link seperti jendela: selalu menampilkan isi terbaru dari sumbernya. Pakai Values kalau angka sudah final atau file akan dikirim. Pakai link kalau angka sumber masih bisa berubah dan kamu ingin laporannya mengikuti.

Jawaban: A. !. Contoh: Sheet2!B5.

Tanya jawab

Apakah file sumber harus terbuka supaya link berfungsi?

Tidak harus. Kalau file sumber tertutup, rumus memakai angka terakhir yang tersimpan, dan Excel menawarkan pembaruan ketika file ringkasan dibuka. Namun saat kamu mengedit rumus link-nya, lebih mudah jika kedua file terbuka karena alamat lengkapnya bisa dibuat otomatis lewat klik.

Bagaimana kalau file ringkasan akan dikirim ke orang lain?

Link menunjuk ke lokasi file di komputermu, jadi di komputer lain sumbernya mungkin tidak ditemukan. Kirim kedua file bersama, atau ubah link menjadi angka tetap lewat Edit Links dengan tombol Break Link. Setelah diputus, angkanya tetap tampil tetapi tidak lagi mengikuti file sumber.

Apa arti tanda dolar pada alamat seperti $B$5?

Tanda dolar mengunci alamat supaya tidak bergeser ketika rumus disalin ke kotak lain. Pada link antar file, Excel menuliskannya otomatis sehingga rumus selalu menunjuk persis ke kotak yang kamu klik. Tanda ini tidak berhubungan dengan mata uang dan tidak memengaruhi angka yang ditampilkan.

Ringkasan

Link antar sheet dan file membuat rumus mengambil angka langsung dari sumbernya, sehingga hasil selalu mengikuti data terbaru. Jaga file sumber tetap di tempatnya, dan perbarui lewat Edit Links bila lokasinya berubah.
