Variabel dan Option Explicit

Variabel adalah tempat menyimpan nilai sementara. Option Explicit memaksa kamu mendeklarasikan setiap variabel sehingga salah ketik langsung ketahuan.

Intinya

Variabel itu seperti kotak berlabel. Kamu memberi nama pada kotak, lalu menyimpan sesuatu di dalamnya.

Bayangkan begini

Bayangkan kotak penyimpanan dengan label "umur". Kamu menaruh angka 17 di dalamnya. Nanti, kamu menyebut "umur" dan VBA tahu kamu maksud angka 17. Option Explicit seperti aturan: semua kotak harus diberi label sebelum dipakai, supaya kamu tidak tersesat gara-gara salah menulis nama.

Buka versi interaktif
Dim nama As String
Dim umur As Integer

Langkah praktik

  1. Tulis Option Explicit di baris pertama modul.
  2. Buat variabel dengan Dim nama As Tipe, misalnya Dim umur As Integer.
  3. Variabel di dalam Sub hanya berlaku di Sub itu (lokal).
  4. Variabel di bagian atas modul berlaku untuk semua Sub di modul itu. Public berlaku untuk seluruh proyek.

Tips

Tipe yang umum: String (tulisan), Integer dan Long (bilangan bulat), Double (angka desimal), Boolean (benar atau salah).

Kapan dipakai

Kamu butuh variabel setiap kali kode harus mengingat sesuatu sebentar. Misalnya kasir toko yang ingin macro mengalikan harga satuan dengan jumlah barang lalu menampilkan totalnya. Atau guru yang menyimpan nilai tertinggi sementara sambil memeriksa satu per satu nilai siswa. Dengan Option Explicit di atas modul, salah ketik nama variabel langsung ketahuan sebelum macro jalan, sehingga hasil hitunganmu tidak diam-diam salah.

Contoh

Option Explicit
Sub HitungHarga()
    Dim harga As Long
    Dim jumlah As Long
    harga = 5000
    jumlah = 3
    MsgBox "Total: " & harga * jumlah
End Sub

Pada modul, baris pertama Option Explicit mewajibkan semua variabel dideklarasikan. Di dalam Sub HitungHarga(), Dim harga As Long dan Dim jumlah As Long menyiapkan dua kotak penyimpanan bertipe bilangan bulat. Baris harga = 5000 mengisi kotak harga dengan angka latihan, dan jumlah = 3 mengisi kotak jumlah. Baris MsgBox "Total: " & harga * jumlah mengalikan keduanya, menyambung hasilnya dengan tulisan, lalu menampilkan kotak pesan bertuliskan Total: 15000. Kalau kamu salah mengetik jumlh di baris itu, Excel langsung memberi tahu bahwa variabel belum didefinisikan, sebelum macro sempat berjalan. Cobalah mengganti angka latihannya untuk melihat hasil yang berbeda.

Kesalahan yang sering terjadi

  • Muncul pesan Compile error: Variable not defined

    Penyebab: Option Explicit aktif, dan nama itu belum dideklarasikan atau salah ketik.

    Solusi: Periksa ejaan nama variabel. Kalau memang variabel baru, tambahkan baris Dim untuknya.

  • Muncul Run-time error 13: Type mismatch

    Penyebab: Nilai yang disimpan tidak cocok dengan tipe variabel, misalnya tulisan abc dimasukkan ke variabel Integer.

    Solusi: Pastikan isi yang dimasukkan sesuai tipe, atau ganti tipenya menjadi String bila isinya tulisan.

  • Muncul Run-time error 6: Overflow

    Penyebab: Tipe Integer hanya menampung bilangan bulat sampai 32767, sehingga hasil yang lebih besar tidak muat.

    Solusi: Ganti tipe variabel menjadi Long, yang daya tampungnya jauh lebih besar.

  • Variabel kosong ketika Sub lain berjalan

    Penyebab: Variabel yang dideklarasikan di dalam Sub hanya hidup selama Sub itu berjalan.

    Solusi: Pindahkan baris Dim ke bagian atas modul, di bawah Option Explicit, supaya semua Sub di modul itu bisa memakainya.

Jangan tertukar

Variabel mirip kotak di lembar kerja karena sama-sama menyimpan nilai, tetapi sifatnya berbeda. Isi kotak lembar kerja tampil di layar dan tersimpan di file. Variabel hanya hidup di memori selama macro berjalan, lalu hilang begitu macro selesai. Pakai variabel untuk catatan sementara di dalam kode. Pakai kotak lembar kerja untuk data yang harus tetap ada dan bisa dilihat orang.

Uji pemahaman

Fungsi Option Explicit adalah...

  1. Mewajibkan deklarasi variabel
  2. Mempercepat macro
  3. Menyembunyikan kode
  4. Menghapus komentar
Lihat jawaban

Jawaban: A. Mewajibkan deklarasi variabel. Variabel yang tidak dideklarasikan menimbulkan galat saat kompilasi.

Tanya jawab

Apakah Option Explicit wajib ditulis?

Tidak wajib, tetapi sangat dianjurkan. Tanpanya, VBA membuat variabel baru begitu melihat nama yang belum dikenal, jadi salah ketik tidak ketahuan dan hasil hitungan bisa meleset diam-diam. Dengan Option Explicit, kesalahan seperti itu langsung ditolak sebelum macro berjalan, sehingga lebih mudah diperbaiki.

Bagaimana agar Option Explicit muncul otomatis di modul baru?

Di editor VBA, buka Tools, Options, lalu pada tab Editor centang Require Variable Declaration. Setelah itu setiap modul baru otomatis diawali baris Option Explicit. Modul lama tidak berubah, jadi untuk modul yang sudah ada kamu masih perlu mengetik barisnya sendiri di paling atas.

Apa bedanya tipe Integer dan Long?

Keduanya menyimpan bilangan bulat. Integer hanya menampung sampai 32767, sedangkan Long menampung sampai sekitar dua miliar. Karena nomor baris di lembar kerja bisa melebihi 32767, banyak orang memakai Long untuk semua bilangan bulat supaya tidak kena error Overflow di tengah jalan.

Ringkasan

Variabel adalah kotak bernama untuk menyimpan nilai sementara. Deklarasikan dengan Dim, pilih tipe yang pas, dan tulis Option Explicit di atas modul agar salah ketik nama langsung ketahuan.
