Memindahkan dan menyalin sheet ke file lain

Move or Copy memindahkan satu sheet beserta seluruh isinya ke file Excel lain, atau membuat salinannya.

Intinya

Klik kanan nama sheet, lalu pilih Move or Copy.

Bayangkan begini

Sheet itu seperti selembar kertas di dalam map. Move or Copy memindahkan kertas itu ke map lain. Kalau kamu centang Create a copy, kertas aslinya tetap di map lama dan map baru mendapat fotokopinya.

Penjelasan untuk pemula

Bayangkan kamu guru yang menyimpan satu map besar berisi lembar nilai tiap kelas. Suatu hari kepala sekolah meminta lembar kelas 8B saja. Kamu tidak mungkin menyerahkan seluruh map. Kamu juga tidak mau menulis ulang isi lembar itu dari awal. Yang kamu butuhkan adalah mengambil satu lembar, lalu menaruhnya di map lain. Di Excel, satu file disebut workbook atau buku kerja. Di dalamnya ada beberapa sheet, yaitu lembar kerja. Nama tiap sheet tampak pada tab di bagian bawah layar. Masalahnya muncul ketika satu sheet harus pindah ke file lain, atau ketika kamu ingin salinannya di file lain. Menyalin sel satu per satu lewat Ctrl+C dan Ctrl+V sering gagal. Lebar kolom kembali ke ukuran awal, rumus bisa bergeser, dan format hilang. Excel menyediakan perintah khusus bernama Move or Copy. Perintah ini membawa seluruh isi sheet sekaligus: angka, rumus, warna, lebar kolom, dan pengaturan cetak. Ada dua pilihan. Move berarti sheet berpindah dan hilang dari tempat lama. Copy berarti sheet asli tetap ada dan file tujuan mendapat salinannya. Perbedaannya hanya satu kotak centang kecil, yaitu Create a copy. Halaman ini membimbingmu mencobanya dari file kosong, lalu memeriksa hasilnya.

Istilah penting

Workbook (buku kerja)
Satu file Excel utuh. Di dalam satu workbook ada satu sheet atau lebih, sama seperti satu map yang berisi beberapa lembar kertas.
Tab sheet
Kotak bernama di bagian bawah layar yang mewakili satu sheet. Klik untuk berpindah sheet, klik kanan untuk membuka daftar perintah, klik dua kali untuk mengganti nama.
Move or Copy
Perintah di menu klik kanan tab sheet. Dengan perintah ini kamu memindahkan atau menyalin satu sheet ke posisi lain, di file yang sama atau di file lain.
To book
Kotak pilihan di jendela Move or Copy untuk menentukan file tujuan. Isinya hanya file Excel yang sedang terbuka, ditambah pilihan new book.
Before sheet
Daftar untuk menentukan posisi sheet baru di file tujuan, yaitu di depan sheet mana. Pilih move to end kalau mau menaruhnya paling belakang.
Create a copy
Kotak centang yang mengubah Move menjadi Copy. Kalau dicentang, sheet asli tetap di tempatnya. Kalau tidak, sheet asli ikut berpindah.
New book
Pilihan di To book untuk membuat file Excel baru yang langsung berisi sheet yang kamu pindahkan atau salin, tanpa perlu membuat file kosong lebih dulu.

Langkah praktik

  1. Klik kanan nama sheet di bagian bawah layar, lalu pilih Move or Copy.
  2. Di kotak To book, pilih file tujuan.
  3. Centang Create a copy kalau sheet yang asli tetap harus ada.
  4. Klik OK.

Panduan langkah demi langkah

  1. Buka file asal dan lihat tab sheet

    Buka file yang berisi sheet yang mau dibawa. Lihat deretan tab di bagian bawah layar dan temukan nama sheet itu. Klik sekali pada tabnya sampai isinya tampil. Dengan begitu kamu yakin sedang membawa sheet yang benar, bukan sheet lain yang namanya mirip. Cek juga judul file di bagian atas jendela.

  2. Siapkan file tujuan

    Tekan Ctrl+N untuk membuat file kosong, atau buka file lain yang sudah ada. Biarkan kedua file terbuka bersamaan. Kamu bisa berpindah antarjendela lewat bilah tugas Windows atau Alt+Tab. Ingat bahwa daftar tujuan nanti hanya menampilkan file yang sedang terbuka, jadi langkah ini tidak boleh dilewati.

  3. Klik kanan tab sheet yang mau dibawa

    Kembali ke file asal, lalu klik kanan pada tab sheet. Sebuah daftar perintah muncul, misalnya Insert, Delete, Rename, dan Move or Copy. Klik Move or Copy. Jendela kecil terbuka dengan judul yang sama, dan di dalamnya ada kotak To book, Before sheet, dan satu kotak centang.

  4. Pilih file tujuan di To book

    Klik panah pada kotak To book. Daftar menampilkan nama file yang terbuka, ditambah new book. Pilih file tujuanmu. Perhatikan bahwa isi kotak Before sheet di bawahnya langsung berganti menjadi daftar sheet milik file yang kamu pilih. Itu tanda Excel sudah membaca file tujuan dengan benar, jadi kamu bisa lanjut.

  5. Tentukan posisi di Before sheet

    Pilih sheet yang akan berada tepat di belakang sheet kiriman. Kalau tidak ada preferensi, pilih move to end supaya sheet baru ada di paling kanan. Kalau memakai file kosong, daftarnya hanya berisi Sheet1, dan memilih move to end sudah cukup untuk pemula. Posisinya masih bisa digeser belakangan dengan menyeret tab.

  6. Putuskan: pindah atau salin

    Lihat kotak centang Create a copy di bagian bawah jendela. Centang kalau sheet asli harus tetap ada di file asal. Kosongkan kalau sheet itu memang pindah rumah. Keputusan ini tidak bisa ditebak oleh Excel, jadi baca sekali lagi sebelum menekan OK, terutama kalau file asalmu satu-satunya salinan.

  7. Klik OK dan baca layarmu

    Klik OK. Excel membuka file tujuan dan menampilkan sheet yang baru tiba. Lihat tab di bagian bawah, nama sheet kirimanmu seharusnya ada di sana. Kalau tadi kamu memilih Copy, sheet yang sama masih ada di file asal. Kalau memilih Move, sheet itu sudah tidak ada di sana.

  8. Periksa isi sheet di tempat baru

    Klik beberapa kotak yang berisi rumus, lalu lihat Formula Bar di atas lembar kerja. Pastikan angka, warna, dan lebar kolom sama seperti aslinya. Rumus yang hanya menunjuk kotak dalam sheet itu sendiri tetap bekerja. Rumus yang menunjuk sheet lain perlu perhatian khusus, seperti pada latihan ketiga di halaman ini.

  9. Beri nama dan simpan file tujuan

    Kalau namanya bertambah angka dalam kurung, klik dua kali pada tab dan ketik nama yang kamu mau. Lalu tekan Ctrl+S. Untuk file baru, Excel meminta nama file dan lokasi penyimpanan. Pilih folder yang mudah kamu temukan lagi, supaya sheet kirimanmu tidak hilang bersama jendela yang tertutup.

  10. Cek ulang file asal

    Terakhir, buka file asal dan periksa jumlah sheetnya. Kalau tadi memilih Copy, jumlahnya tidak berubah. Kalau memilih Move, jumlahnya berkurang satu. Kalau hasilnya tidak sesuai harapan, tekan Ctrl+Z sebelum melakukan hal lain, atau pindahkan kembali sheet itu dengan perintah yang sama. Jangan menutup file sebelum yakin semuanya benar.

Kapan dipakai

Move or Copy berguna ketika satu sheet harus pindah rumah. Wali kelas punya file besar berisi sheet tiap murid, lalu ingin memberikan sheet seorang murid kepada orang tuanya sebagai file tersendiri. Pemilik toko memakai sheet rekap bulan lalu sebagai contoh bulan ini, jadi ia menyalinnya ke file baru lalu mengosongkan datanya. Cara ini menjaga susunan, rumus, dan format sheet tetap utuh tanpa mengetik ulang apa pun.

Contoh

Seorang wali kelas punya file Nilai Kelas dengan sheet bernama Budi. Ia ingin mengirim sheet itu sebagai file terpisah. Pertama ia membuat file kosong baru dan membiarkan kedua file terbuka. Di file Nilai Kelas, klik kanan tab sheet Budi, lalu pilih Move or Copy. Pada kotak To book, ia memilih file baru, lalu mencentang Create a copy supaya sheet aslinya tetap ada di file kelas. Setelah mengklik OK, sheet Budi muncul di file baru, lengkap dengan format dan rumusnya. Ia lalu menyimpan file baru itu. Cek lagi file barunya sebelum dikirim.

Contoh kasus lanjutan

Kasus 1: Koperasi menyalin sheet Maret sebagai bahan bulan April

Bu Lilis mengurus koperasi simpan pinjam kecil. Tiap bulan ia membuat satu sheet berisi simpanan dan pinjaman anggota. Ia ingin memakai sheet Maret sebagai contoh untuk file baru bernama April, lalu mengganti angkanya. Sheet Maret harus tetap utuh di file lama untuk arsip. Ia ingin rumus total ikut terbawa. Berikut isi sheet Maret.

Ia memeriksa B7. Rumus =SUM(B2:B6) menjumlahkan lima simpanan dan hasilnya 2650000. Rumus C7 menjumlahkan pinjaman dan hasilnya 650000. Rumus B8 mengurangi keduanya dan hasilnya 2000000. Semua rumus itu hanya menunjuk kotak di sheet yang sama, jadi tidak perlu diperbaiki. Ia lalu mengganti nama sheet menjadi April dan menimpa angka anggota. Sheet Maret di file lama masih lengkap, karena kotak Create a copy dicentang.

Pak Rudi punya file Toko dengan sheet Kasir dan Stok. Ia menyewa pegawai gudang yang hanya perlu melihat stok. Pak Rudi ingin sheet Stok pindah ke file Gudang, bukan disalin, supaya data stok tidak ada di dua tempat dan tidak saling berbeda. Berikut isi sheet Stok yang akan ia pindahkan.

Setelah OK, sheet Stok pindah ke Gudang dan hilang dari file Toko. Ia memeriksa rumus. =SUM(B2:B6) menjumlahkan 40, 18, 30, 12, dan 50, hasilnya 150. Rumus penanda pada beras menghasilkan Cukup karena 40 tidak lebih kecil dari 20. Pada gula hasilnya Beli karena 18 lebih kecil dari 25. Rumus-rumus ini hanya menunjuk kotak di dalam sheet Stok, jadi tetap bekerja. Sekarang data stok hanya ada di satu file, dan tidak ada salinan lama yang bisa membingungkan.

Latihan mandiri

Coba kerjakan sendiri di Excel dulu, baru cocokkan dengan jawabannya.

Latihan 1

Buka file baru dan ketik nama barang apa saja di sheet pertama. Salin sheet itu ke file yang sama sebagai cadangan, tanpa memakai menu klik kanan. Setelah itu lihat nama sheet baru yang muncul dan tuliskan nama yang diberikan Excel.

Petunjuk: Tahan Ctrl, klik tab sheet, lalu seret sedikit ke kanan dan lepaskan. Perhatikan segitiga kecil yang muncul saat menyeret, lalu baca tab baru.

Lihat jawaban

Sheet salinan muncul di sebelah kanan, dengan nama yang sama ditambah nomor, misalnya Sheet1 (2). Isinya persis sama dengan sheet asli. Cara yang sama bisa dilakukan lewat Move or Copy dengan Create a copy dicentang dan To book diisi nama file yang sedang dipakai.

Latihan 2

Sheet Penjualan berisi jumlah kopi dan teh per hari seperti pada tabel. Salin sheet itu ke new book, lalu tambahkan rumus jumlah kopi di sheet salinan. Hasilnya harus sama dengan rumus yang sama di sheet asli.

Lihat jawaban

Rumus: =SUM(B2:B4). Hasil: 36.

Rumus =SUM(B2:B4) di B5 menjumlahkan 12, 15, dan 9 sehingga hasilnya 36. Di sheet asli dan di sheet salinan hasilnya sama karena datanya sama. Kalau kamu mengubah angka di salinan, sheet asli tidak ikut berubah, sebab keduanya sudah terpisah.

Latihan 3

Sheet Rekap menghitung dengan rumus yang menunjuk sheet Harga, misalnya =Harga!B2*C2. Kamu menyalin hanya sheet Rekap ke file lain. Jelaskan apa yang terjadi pada rumusnya, lalu tuliskan cara membuat angkanya berdiri sendiri tanpa menunjuk file lama.

Petunjuk: Rumus bisa menunjuk ke file asal. Pikirkan cara mengubah rumus menjadi angka biasa, yaitu lewat Copy lalu Paste Special dengan pilihan Values.

Lihat jawaban

Rumus di salinan tetap menunjuk sheet Harga yang tertinggal, sehingga Excel mengisinya dengan alamat file asal. Supaya mandiri, sorot kotak hasil, tekan Ctrl+C, lalu Ctrl+Alt+V dan pilih Values. Rumus berganti angka tetap. Cara lain: salin juga sheet Harga ke file yang sama.

Tips lanjutan

  • Pindahkan sheet dengan menyeret

    Di dalam satu file, kamu bisa memindahkan sheet dengan menyeret tabnya ke kiri atau kanan. Menahan Ctrl saat menyeret membuat salinan, bukan perpindahan. Cara ini cepat untuk mengatur urutan. Untuk pindah antarfile, tetap pakai Move or Copy supaya pilihan file tujuannya jelas.

  • Ganti nama sheet sebelum dikirim

    Salinan sering bernama seperti Januari (2). Klik dua kali pada tab lalu ketik nama yang benar. Nama yang rapi mencegah salah paham ketika orang lain membuka file itu, dan membuat rumus yang menunjuk sheet tersebut lebih mudah dibaca. Lakukan ini sebelum file dikirim, bukan sesudahnya, supaya orang lain tidak menerima nama yang membingungkan.

  • Kosongkan data contoh dengan hati-hati

    Kalau sheet salinan dipakai sebagai kerangka, hapus hanya kotak berisi angka, bukan kotak berisi rumus. Sorot rentang angkanya, tekan Delete, lalu periksa apakah rumus total berubah menjadi nol. Itu tanda rumusnya masih utuh dan siap dipakai. Kalau hasilnya tetap berisi angka lama, berarti kamu tadi ikut menghapus rumusnya dan harus mengembalikannya dengan Ctrl+Z.

  • Pindah antarsheet dengan papan ketik

    Saat bekerja dengan banyak sheet, Ctrl+Page Down pindah ke sheet berikutnya dan Ctrl+Page Up ke sheet sebelumnya. Dua pintasan ini mempercepat pemeriksaan setelah kamu memindahkan beberapa sheet sekaligus ke file baru. Kamu tidak perlu mengarahkan mouse ke bagian bawah layar untuk mengklik tab satu per satu, dan kedua tanganmu tetap di papan ketik.

  • Simpan cadangan sebelum memindahkan

    Sebelum memindahkan sheet penting, simpan salinan file asal dengan nama berbeda. Kalau salah centang dan sheet asli hilang, kamu masih punya cadangan. Kebiasaan ini hanya butuh beberapa detik dan melindungi data yang butuh waktu lama untuk disusun. Beri nama cadangan dengan tanggal agar mudah dikenali.

Kesalahan yang sering terjadi

  • Sheet asli hilang dari file lama setelah dipindah

    Penyebab: Create a copy tidak dicentang, sehingga Excel memindahkan sheet, bukan menyalinnya.

    Solusi: Tekan Ctrl+Z bila belum diubah lagi. Atau pindahkan sheet itu kembali lewat Move or Copy.

  • File tujuan tidak muncul di daftar To book

    Penyebab: Daftar itu hanya berisi file Excel yang sedang terbuka, bukan semua file di komputer.

    Solusi: Buka dulu file tujuan, lalu ulangi Move or Copy. Atau pilih new book untuk membuat file baru.

  • Rumus di sheet salinan masih menunjuk ke file lama

    Penyebab: Rumus itu mengambil data dari sheet lain yang tidak ikut dipindah, sehingga Excel mempertahankan rujukan ke file asal.

    Solusi: Pindahkan atau salin sheet sumbernya juga, lalu arahkan ulang rumus. Atau ubah rumusnya ke angka dengan Paste Special Values.

  • Nama sheet bertambah (2) di belakangnya setelah disalin

    Penyebab: Dalam satu file tidak boleh ada dua sheet bernama sama, sehingga Excel menambahkan nomor.

    Solusi: Klik dua kali nama sheet di bagian bawah, lalu ketik nama yang kamu inginkan.

Jangan tertukar

Move or Copy sering dibandingkan dengan menyorot semua kotak, menyalin, lalu menempel di sheet baru. Cara terakhir hanya membawa isi kotak dan sebagian format. Pengaturan sheet seperti lebar kolom, area cetak, dan objek tidak selalu ikut. Move or Copy membawa seluruh sheet sebagai satu paket, jadi hasilnya sama persis dengan aslinya.

Cek cepat sebelum selesai

  • Nama sheet kiriman muncul di tab file tujuan, di posisi yang kamu inginkan.
  • Kotak Create a copy sudah sesuai niatmu, pindah atau salin, sebelum kamu menekan OK.
  • Rumus di sheet baru menampilkan angka yang sama dengan sheet asli.
  • Tidak ada rumus yang masih menyebut nama file lama di Formula Bar.
  • Nama sheet salinan sudah kamu ganti kalau ada tambahan nomor dalam kurung.
  • File tujuan sudah disimpan dengan Ctrl+S di folder yang mudah ditemukan lagi.

Tanya jawab

Bagaimana cara menyalin sheet di dalam file yang sama?

Pakai Move or Copy yang sama, tetapi pada kotak To book biarkan nama file yang sedang dipakai. Centang Create a copy lalu klik OK. Cara cepatnya, tahan Ctrl sambil menyeret tab sheet ke posisi baru. Salinan akan mendapat nama yang sama dengan tambahan nomor di belakangnya.

Apakah gambar, grafik, dan format ikut terbawa?

Ya. Move or Copy membawa seluruh isi sheet, termasuk rumus, format, lebar kolom, dan objek di dalamnya. Itu kelebihannya dibanding menyalin kotak lalu menempel di sheet kosong. Periksa saja rumus yang menunjuk ke sheet lain karena rujukannya bisa tetap mengarah ke file lama.

Apakah file lain harus disimpan setelah sheet dipindahkan?

Ya. Move or Copy tidak menyimpan file apa pun secara otomatis. File tujuan memuat sheet baru di memori sampai kamu menyimpannya. Kalau sheet dipindah, file asal juga berubah karena sheet tadi tidak ada lagi di sana, jadi simpan keduanya setelah memeriksa hasilnya.

Ringkasan

Klik kanan nama sheet lalu pilih Move or Copy untuk memindahkan sheet ke file lain. Centang Create a copy kalau aslinya harus tetap ada, dan periksa rumus yang masih menunjuk ke file lama setelah sheet tiba.
