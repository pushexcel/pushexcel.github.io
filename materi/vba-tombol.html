Tombol macro dan form isian data

Command Button adalah tombol di lembar kerja. Saat diklik, macro berjalan. UserForm adalah formulir isian yang rapi untuk memasukkan data.

Intinya

Tombol menjalankan macro. Formulir memudahkan orang mengisi data tanpa menyentuh tabel.

Bayangkan begini

Bayangkan mesin ATM. Kamu tidak perlu tahu cara kerja bank di dalamnya. Kamu hanya menekan tombol dan mengisi layar. Tombol dan formulir VBA membuat Excel-mu semudah itu bagi orang lain.

Penjelasan untuk pemula

Bayangkan kamu menyerahkan file Excel ke teman yang takut merusak tabel. Ia harus tahu kolom mana yang diisi, baris mana yang kosong, dan rumus mana yang tidak boleh disentuh. Satu salah klik, dan data berantakan. Solusinya, buat Excel lebih mirip aplikasi: ada tombol yang tinggal ditekan, dan ada formulir yang tinggal diisi. Tombol di lembar kerja bernama Command Button. Di balik tombol itu tersimpan kode VBA yang dijalankan saat tombol diklik. Peristiwa klik itu disebut event, yaitu kejadian yang ditunggu oleh kode. Formulir bernama UserForm. Ia jendela kecil yang muncul di atas lembar kerja, berisi kotak isian bernama TextBox dan tombol Simpan. Orang cukup mengetik di kotak isian lalu menekan tombol. Kode di dalamnya yang memindahkan isian itu ke baris tabel yang benar. Pekerjaan membuat tombol dan formulir selalu terdiri dari dua bagian yang berurutan: menggambar bentuknya, lalu menulis kode yang dijalankan saat tombol diklik. Bagian pertama mirip menyusun tampilan di kertas, bagian kedua mirip pelajaran macro sebelumnya. Di pelajaran ini kamu memasang satu tombol, membuat satu formulir dengan dua kotak isian, dan belajar mengujinya dengan aman di file latihan.

Istilah penting

Command Button
Tombol yang kamu gambar di lembar kerja. Saat diklik, ia menjalankan kode VBA yang kamu tulis untuk tombol itu.
UserForm
Jendela formulir buatanmu sendiri di editor VBA. Ia berisi kotak isian dan tombol, lalu muncul di atas lembar kerja ketika dipanggil.
TextBox
Kotak isian di dalam UserForm tempat orang mengetik. Isinya dibaca kode lewat properti Value, lalu ditulis ke kotak di lembar kerja.
Design Mode
Mode di tab Developer untuk menyusun dan mengedit tombol. Selama mode ini aktif, tombol hanya bisa dipilih, tidak bisa dijalankan.
Event
Kejadian yang ditunggu kode, misalnya klik tombol. Kode untuk satu kejadian ditulis dalam Sub bernama seperti CommandButton1_Click.
Properties
Jendela pengaturan sebuah tombol atau kotak isian. Di sini kamu mengganti nama, tulisan pada tombol, dan beberapa sifat lain.
File .xlsm
Format file Excel yang boleh menyimpan macro. File biasa .xlsx tidak menyimpan kode, sehingga tombolmu kehilangan isi saat dibuka lagi.

Langkah praktik

  1. Buka Developer, Insert, lalu Command Button (ActiveX Control). Gambar tombol di lembar kerja.
  2. Klik ganda tombol itu. Editor VBA terbuka dan kamu bisa menulis kode untuk klik tombol.
  3. Contoh tombol hapus: Range("A2:C100").ClearContents.
  4. Untuk formulir: di editor klik Insert lalu UserForm. Tambahkan TextBox untuk isian dan tombol Simpan.
  5. Kode tombol Simpan menulis isi TextBox ke baris kosong berikutnya.
  6. Matikan Design Mode supaya tombol bisa diklik.

Tips

Tombol ActiveX hanya bekerja di Excel untuk Windows.

Panduan langkah demi langkah

  1. Siapkan file latihan dan tab Developer

    Buka file kosong untuk latihan. Kalau tab Developer belum terlihat, buka File, Options, Customize Ribbon, lalu centang Developer dan klik OK. Sesudahnya tab itu muncul di barisan tab. Simpan file sebagai .xlsm sejak awal, supaya kode yang kamu tulis tidak hilang saat file ditutup dan dibuka lagi.

  2. Buat kepala tabel

    Ketik Nama di A1 dan Jumlah di B1. Dua judul ini menandai tempat data masuk. Kode yang akan kamu tulis mencari baris kosong di bawahnya, jadi judul harus ada dan tidak boleh dikosongkan. Pastikan tidak ada isi lain di kolom A di bawah judul, supaya hasil pencarian baris kosong benar.

  3. Gambar tombol di lembar kerja

    Di tab Developer, klik Insert, lalu pilih Command Button di bagian ActiveX Controls. Tarik mouse di lembar kerja untuk menggambar tombol. Biasanya Design Mode otomatis aktif saat tombol dipasang, jadi tombol hanya bisa dipilih. Ubah tulisan pada tombol lewat Properties pada baris Caption, misalnya menjadi Catat Waktu.

  4. Buka kode tombol

    Selagi Design Mode aktif, klik ganda tombol tadi. Editor VBA terbuka dengan kerangka Private Sub CommandButton1_Click() dan baris End Sub. Kode di antara dua baris itu berjalan setiap kali tombol diklik. Perhatikan bahwa kode ini milik lembar tempat tombol berada, dan itu bukan module biasa.

  5. Ketik kode dan matikan Design Mode

    Ketik dua baris ini di antara kerangka tadi: Range("B1").Value = Now dan Range("B1").NumberFormat = "dd/mm/yyyy hh:mm". Tutup editor, lalu klik Design Mode di tab Developer sampai tidak aktif lagi. Sekarang tombol bisa diklik. Klik sekali dan lihat kotak B1 berisi tanggal dan jam. Bila tidak ada reaksi, periksa lagi apakah Design Mode masih aktif.

  6. Buat UserForm baru

    Tekan Alt+F11, lalu pilih Insert dan UserForm di editor. Sebuah jendela kosong muncul bersama kotak alat berisi daftar kontrol. Dari kotak alat itu kamu bisa menarik kontrol ke formulir. Jika kotak alat tidak terlihat, klik formulirnya dulu supaya terpilih. Nama bawaan formulir pertama adalah UserForm1.

  7. Tambahkan dua kotak isian dan tombol

    Tarik dua TextBox ke formulir, satu untuk nama dan satu untuk jumlah. Tarik satu CommandButton, lalu ubah Caption-nya menjadi Simpan lewat jendela Properties, yang bisa dibuka dengan F4. Tambahkan dua Label di sebelah kotak isian supaya orang tahu apa yang harus diketik. Label hanya tulisan penjelas, jadi tidak perlu kode apa pun.

  8. Tulis kode tombol Simpan

    Klik ganda tombol Simpan di formulir. Editor menampilkan kerangka CommandButton1_Click milik formulir. Ketik kode dari kasus kedua pelajaran ini. Kode itu memeriksa isian jumlah, mencari baris kosong, menulis dua isian, lalu mengosongkan kotak untuk isian berikutnya. Baca ulang tiap baris sambil menebak fungsinya, lalu cocokkan tebakanmu dengan pembahasan kasus itu.

  9. Coba formulir tanpa tombol di lembar

    Klik formulir di editor, lalu tekan F5. Formulir tampil di atas lembar kerja. Ketik Sari dan 5000, lalu klik Simpan. Tutup formulir, dan periksa A2 dan B2. Jika data muncul di baris yang benar, kodenya bekerja. Ulangi dengan isian kedua untuk memastikan data masuk ke baris di bawahnya. Coba juga ketik huruf di kotak jumlah untuk melihat pesan penolakan.

  10. Sambungkan formulir ke tombol

    Kembali ke kode tombol di lembar kerja dan ganti isinya dengan UserForm1.Show. Matikan Design Mode, lalu klik tombolnya. Formulir tampil. Ketik satu isian untuk menguji alurnya dari awal sampai akhir. Simpan file sebagai .xlsm sebelum mengirimnya, dan beri tahu penerima bahwa macro perlu diizinkan. Tanpa pemberitahuan itu, tombolmu tampak mati bagi orang lain.

Kapan dipakai

Kamu membuat tombol dan formulir saat file Excel dipakai orang lain yang tidak nyaman mengutak-atik tabel. Misalnya petugas perpustakaan yang mencatat nama peminjam lewat formulir, lalu namanya masuk ke baris kosong berikutnya. Atau bendahara yang menyediakan tombol Bersihkan untuk mengosongkan kolom isian sebelum bulan baru. Orang cukup mengisi kotak dan menekan tombol, sehingga risiko tabel rusak karena salah ketik atau salah hapus jadi jauh lebih kecil.

Contoh

Private Sub CommandButton1_Click()
    Dim baris As Long
    With ActiveSheet
        baris = .Cells(.Rows.Count, 1).End(xlUp).Row + 1
        .Cells(baris, 1).Value = TextBox1.Value
    End With
    TextBox1.Value = ""
End Sub

Misalkan judul kolom Nama sudah ada di A1. Kamu membuat UserForm dengan satu TextBox dan satu tombol bertulisan Simpan, lalu klik ganda tombol itu dan menempelkan kode di atas. Baris Dim baris As Long menyiapkan nomor baris. Baris dengan End(xlUp) mencari isi terakhir di kolom A lalu menambah 1, jadi hasilnya baris kosong berikutnya, yaitu A2 pada isian pertama. Baris .Cells(baris, 1).Value = TextBox1.Value menulis isi TextBox ke sana. Baris terakhir mengosongkan TextBox. Ketik Sari lalu klik Simpan, dan Sari muncul di A2. Ketik Budi, dan Budi muncul di A3. Kata Simpan di sini artinya menulis ke lembar, bukan menyimpan file.

Contoh kasus lanjutan

Kasus 1: Tombol pencatat waktu pengecekan alat

Bu Mira memeriksa alat laboratorium sekolah setiap pagi dan ingin mencatat kapan pengecekan terakhir dilakukan. Ia membuat tombol di lembar kerja. Setiap kali tombol diklik, kotak B1 berisi tanggal dan jam saat itu. Kodenya ia pisahkan menjadi satu Sub di module dan satu baris pemanggil di tombol, supaya Sub yang sama bisa dipakai tombol lain nanti.

' Di module biasa:
Sub CatatWaktu()
    Range("B1").Value = Now
    Range("B1").NumberFormat = "dd/mm/yyyy hh:mm"
End Sub

' Di kode lembar, saat tombol diklik ganda:
Private Sub CommandButton1_Click()
    CatatWaktu
End Sub

Bagian pertama berada di module biasa. Now adalah fungsi VBA yang memberi tanggal dan jam saat itu, dan Range("B1").Value menerimanya. Baris berikutnya mengatur tampilan B1 supaya tampil dengan pola hari, bulan, tahun, lalu jam dan menit. Baris itu memastikan polanya persis seperti yang kamu inginkan. Bagian kedua adalah kode tombol. Ia hanya memanggil CatatWaktu, sama seperti kamu menyebut nama Sub. Dengan pembagian ini, perubahan cukup dilakukan di satu tempat. Setelah Design Mode dimatikan dan tombol diklik, B1 terisi waktu klik. Klik lagi, dan isinya diganti waktu yang baru, jadi hanya satu catatan terakhir yang tersimpan. Kalau kamu ingin riwayat, kamu perlu menulis ke baris kosong berikutnya.

Kasus 2: Formulir setoran kas kelas

Bendahara kelas, Sari, mencatat setoran kas dari teman-temannya. Ia membuat UserForm dengan dua TextBox: nama di TextBox1 dan jumlah di TextBox2. Judul Nama dan Jumlah sudah ada di A1 dan B1. Setiap kali ia menekan Simpan, data harus masuk ke baris kosong berikutnya. Kalau jumlah yang diketik bukan angka, formulir harus menolaknya dengan pesan, dan tidak menulis apa pun ke tabel.

Private Sub CommandButton1_Click()
    Dim baris As Long
    If Not IsNumeric(TextBox2.Value) Then
        MsgBox "Jumlah harus berupa angka."
        Exit Sub
    End If
    baris = Cells(Rows.Count, 1).End(xlUp).Row + 1
    Cells(baris, 1).Value = TextBox1.Value
    Cells(baris, 2).Value = CDbl(TextBox2.Value)
    TextBox1.Value = ""
    TextBox2.Value = ""
End Sub

Blok If bekerja sebagai penjaga. IsNumeric memeriksa apakah isi TextBox2 bisa dibaca sebagai angka. Bila tidak, kotak pesan muncul dan Exit Sub menghentikan Sub, sehingga lembar kerja tidak disentuh. Kalau lolos, baris berikutnya mencari isi terakhir di kolom A dari bawah lembar ke atas, lalu menambah 1. Dengan judul di A1 dan tabel masih kosong, hasilnya baris 2. Nama Sari ditulis ke A2, dan jumlah 5000 ditulis ke B2 sebagai angka lewat CDbl. Dua baris terakhir mengosongkan kotak isian. Isian berikutnya otomatis jatuh ke baris 3. Bila kamu mengetik abc di kotak jumlah, kotak pesan muncul dan tabel tidak berubah. Kotak nama kosong masih lolos, dan itu kelemahan yang bisa kamu perbaiki di latihan.

Latihan mandiri

Coba kerjakan sendiri di Excel dulu, baru cocokkan dengan jawabannya.

Latihan 1

Ubah Sub CatatWaktu di kasus pertama agar tulisan Dicatat: ditulis di A2 dan waktunya di B2, tanpa menyentuh B1. Tulis tiga baris pengganti isi Sub itu dan jelaskan apa yang tampak di lembar setelah tombol diklik.

Petunjuk: Cukup ganti alamat kotak dan tambah satu baris untuk tulisan penanda. Format tanggal harus dipasang ke kotak yang sama dengan tempat Now ditulis.

Lihat jawaban

Tulis Range("A2").Value = "Dicatat:", lalu Range("B2").Value = Now, lalu Range("B2").NumberFormat = "dd/mm/yyyy hh:mm". Setelah klik, A2 berisi Dicatat: dan B2 berisi tanggal dan jam klik. B1 tidak berubah sama sekali. Klik berikutnya hanya mengganti isi B2 dengan waktu terbaru.

Latihan 2

Tambahkan satu baris pada kode formulir kasus kedua supaya setelah data tersimpan muncul pesan berbunyi Tersimpan di baris 2 untuk isian pertama. Baris itu harus ditaruh di mana, dan angka 2 diambil dari mana, bukan diketik sendiri?

Petunjuk: Nomor baris sudah ada di variabel baris. Pesan harus muncul sesudah data benar-benar ditulis, tetapi sebelum kotak isian dikosongkan.

Lihat jawaban

Taruh MsgBox "Tersimpan di baris " & baris tepat setelah baris yang menulis jumlah. Angkanya diambil dari variabel baris, yang berisi 2 pada isian pertama dan 3 pada isian kedua. Kalau ditaruh sebelum penulisan, pesannya muncul terlalu dini.

Latihan 3

Kotak nama (TextBox1) di kasus kedua bisa dibiarkan kosong, dan datanya tetap tertulis. Tulis blok kode tambahan yang menolak nama kosong atau yang hanya berisi spasi. Jelaskan di mana blok itu ditaruh dan mengapa IsNumeric tidak bisa dipakai untuk menjaga kotak nama.

Petunjuk: Pakai Trim untuk membuang spasi, lalu bandingkan hasilnya dengan tulisan kosong. Blok ini serupa dengan blok penjaga jumlah, dan kedua penjaga harus berada sebelum penulisan.

Lihat jawaban

Taruh sebelum penjaga jumlah: If Trim(TextBox1.Value) = "" Then, MsgBox "Nama harus diisi.", Exit Sub, End If. Trim membuang spasi sehingga isian berupa spasi saja juga ditolak. IsNumeric hanya menilai angka, sedangkan nama berupa huruf, jadi nama yang sah pun dinilai bukan angka.

Tips lanjutan

  • Tambahkan tombol Tutup

    Formulir yang tidak punya cara menutup akan membuat orang bingung. Tambahkan satu CommandButton lagi dengan Caption Tutup. Klik gandanya, lalu tulis Unload Me di antara baris Sub. Perintah itu menutup formulir yang sedang terbuka. Isian yang sudah disimpan tetap aman di lembar kerja, karena penulisannya sudah terjadi saat tombol Simpan diklik.

  • Beri nama yang bermakna

    Nama bawaan seperti TextBox1 dan TextBox2 cepat membingungkan saat formulir punya banyak kotak. Lewat jendela Properties, ganti baris Name menjadi txtNama dan txtJumlah. Setelah itu kodenya menjadi txtNama.Value, yang bisa langsung dibaca artinya. Ganti nama sebelum menulis kode, sebab nama lama di kode tidak otomatis ikut berubah.

  • Siapkan daftar pilihan dengan ComboBox

    Untuk isian yang pilihannya terbatas, misalnya kategori barang, pakai ComboBox. Isi pilihannya saat formulir dibuka, di Sub bernama UserForm_Initialize, dengan baris seperti ComboBox1.AddItem "Sembako". Pilihan yang sudah tersedia mengurangi salah ketik, dan datamu lebih seragam ketika nanti dijumlahkan atau disaring.

  • Atur urutan Tab

    Orang yang mengisi formulir banyak biasanya menekan Tab untuk pindah kotak. Urutannya diatur lewat properti TabIndex pada tiap kontrol. Angka terkecil menjadi yang pertama. Uji dengan menekan Tab berulang kali sampai kursor kembali ke awal, dan pastikan urutannya wajar, dari nama, jumlah, lalu tombol Simpan.

  • Uji di salinan sebelum dibagikan

    Kode yang menulis data akan mengubah lembar kerja, jadi uji di salinan file lebih dulu. Coba isian normal, isian kosong, dan isian yang salah, seperti huruf di kotak jumlah. Baru setelah semua perilaku sesuai, bagikan file .xlsm. Beri catatan singkat bahwa pengguna harus mengizinkan macro supaya tombol bisa bekerja.

Kesalahan yang sering terjadi

  • Tombol di lembar kerja tidak bereaksi saat diklik

    Penyebab: Design Mode masih aktif. Pada mode itu tombol hanya bisa dipilih dan diedit, bukan dijalankan.

    Solusi: Buka tab Developer lalu klik Design Mode sekali lagi sampai tidak tersorot. Setelah itu coba klik tombolnya.

  • Tombol ActiveX tidak berfungsi di komputer Mac

    Penyebab: Kontrol ActiveX hanya tersedia di Excel untuk Windows.

    Solusi: Pakai kontrol dari kelompok Form Controls di menu Insert yang sama bila tersedia, lalu hubungkan ke macro lewat Assign Macro. Atau jalankan macro dari Developer lalu Macros.

  • Data baru menimpa isian yang sudah ada

    Penyebab: Kode memakai nomor baris yang tetap, jadi setiap isian ditulis ke baris yang sama.

    Solusi: Cari baris kosong berikutnya dengan End(xlUp) seperti pada kode di atas, bukan menulis nomor baris sendiri.

  • Tombol tidak jalan setelah file dikirim ke orang lain

    Penyebab: File disimpan sebagai .xlsx sehingga kodenya hilang, atau penerima belum mengizinkan macro.

    Solusi: Simpan sebagai .xlsm. Minta penerima klik Enable Content setelah memastikan file itu dapat dipercaya.

Jangan tertukar

Tombol ActiveX sering dibandingkan dengan tombol Form Control, padahal cara kerjanya berbeda. Tombol ActiveX punya kode klik sendiri di lembar, bisa diatur lewat Properties, dan butuh Design Mode untuk diedit. Tombol Form Control lebih sederhana: kamu tinggal memilih macro yang sudah ada lewat Assign Macro. Pilih ActiveX bila ingin kontrol penuh di Windows, dan Form Control bila cukup menjalankan satu macro.

Cek cepat sebelum selesai

  • File sudah disimpan sebagai .xlsm, dan penerimanya tahu bahwa macro perlu diizinkan.
  • Design Mode sudah dimatikan, sehingga tombol di lembar kerja benar-benar bisa diklik.
  • Judul kolom ada di baris pertama, dan kolom A tidak berisi sisa data lain di bawahnya.
  • Isian kosong dan isian salah, seperti huruf di kotak jumlah, sudah dicoba dan ditolak.
  • Setiap kotak isian dan tombol sudah punya nama atau Caption yang jelas bagi pengguna.
  • Data hasil tes sudah diperiksa di baris yang benar, dan baris kedua tidak menimpa baris pertama.

Tanya jawab

Bagaimana memunculkan UserForm saat tombol di lembar diklik?

Di kode klik tombol, tulis satu baris UserForm1.Show. Nama UserForm1 adalah nama bawaan formulir pertama, jadi sesuaikan kalau kamu menggantinya. Saat tombol diklik, formulir tampil di atas lembar kerja. Untuk mencoba formulir tanpa tombol, kamu bisa memilihnya di editor VBA lalu menekan F5.

Bagaimana mengubah tulisan pada tombol yang sudah dibuat?

Aktifkan Design Mode di tab Developer, lalu klik tombolnya sekali untuk memilih. Buka jendela Properties dari tab yang sama, cari baris Caption, dan ganti isinya. Setelah selesai, matikan Design Mode supaya tombol bisa diklik. Kalau kamu klik ganda saat Design Mode aktif, yang terbuka adalah editor kodenya.

Bagaimana kursor kembali ke TextBox setelah data disimpan?

Tambahkan TextBox1.SetFocus setelah baris yang mengosongkan isiannya. Dengan begitu kursor langsung berada di kotak isian, dan petugas bisa mengetik data berikutnya tanpa mengklik lagi. Cara ini berguna kalau kamu mencatat banyak data berturut-turut dalam satu sesi memakai formulir yang sama.

Ringkasan

Command Button menjalankan macro saat diklik, dan UserForm menyediakan formulir isian yang rapi. Matikan Design Mode agar tombol bisa diklik, simpan sebagai .xlsm, dan cari baris kosong dengan End(xlUp) supaya data tidak tertimpa.
