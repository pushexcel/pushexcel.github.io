Tombol macro dan form isian data

Command Button adalah tombol di lembar kerja. Saat diklik, macro berjalan. UserForm adalah formulir isian yang rapi untuk memasukkan data.

Intinya

Tombol menjalankan macro. Formulir memudahkan orang mengisi data tanpa menyentuh tabel.

Bayangkan begini

Bayangkan mesin ATM. Kamu tidak perlu tahu cara kerja bank di dalamnya. Kamu hanya menekan tombol dan mengisi layar. Tombol dan formulir VBA membuat Excel-mu semudah itu bagi orang lain.

Buka versi interaktif

Langkah praktik

  1. Buka Developer, Insert, lalu Command Button (ActiveX Control). Gambar tombol di lembar kerja.
  2. Klik ganda tombol itu. Editor VBA terbuka dan kamu bisa menulis kode untuk klik tombol.
  3. Contoh tombol hapus: Range("A2:C100").ClearContents.
  4. Untuk formulir: di editor klik Insert lalu UserForm. Tambahkan TextBox untuk isian dan tombol Simpan.
  5. Kode tombol Simpan menulis isi TextBox ke baris kosong berikutnya.
  6. Matikan Design Mode supaya tombol bisa diklik.

Tips

Tombol ActiveX hanya bekerja di Excel untuk Windows.

Kapan dipakai

Kamu membuat tombol dan formulir saat file Excel dipakai orang lain yang tidak nyaman mengutak-atik tabel. Misalnya petugas perpustakaan yang mencatat nama peminjam lewat formulir, lalu namanya masuk ke baris kosong berikutnya. Atau bendahara yang menyediakan tombol Bersihkan untuk mengosongkan kolom isian sebelum bulan baru. Orang cukup mengisi kotak dan menekan tombol, sehingga risiko tabel rusak karena salah ketik atau salah hapus jadi jauh lebih kecil.

Contoh

Private Sub CommandButton1_Click()
    Dim baris As Long
    With ActiveSheet
        baris = .Cells(.Rows.Count, 1).End(xlUp).Row + 1
        .Cells(baris, 1).Value = TextBox1.Value
    End With
    TextBox1.Value = ""
End Sub

Misalkan judul kolom Nama sudah ada di A1. Kamu membuat UserForm dengan satu TextBox dan satu tombol bertulisan Simpan, lalu klik ganda tombol itu dan menempelkan kode di atas. Baris Dim baris As Long menyiapkan nomor baris. Baris dengan End(xlUp) mencari isi terakhir di kolom A lalu menambah 1, jadi hasilnya baris kosong berikutnya, yaitu A2 pada isian pertama. Baris .Cells(baris, 1).Value = TextBox1.Value menulis isi TextBox ke sana. Baris terakhir mengosongkan TextBox. Ketik Sari lalu klik Simpan, dan Sari muncul di A2. Ketik Budi, dan Budi muncul di A3. Kata Simpan di sini artinya menulis ke lembar, bukan menyimpan file.

Kesalahan yang sering terjadi

  • Tombol di lembar kerja tidak bereaksi saat diklik

    Penyebab: Design Mode masih aktif. Pada mode itu tombol hanya bisa dipilih dan diedit, bukan dijalankan.

    Solusi: Buka tab Developer lalu klik Design Mode sekali lagi sampai tidak tersorot. Setelah itu coba klik tombolnya.

  • Tombol ActiveX tidak berfungsi di komputer Mac

    Penyebab: Kontrol ActiveX hanya tersedia di Excel untuk Windows.

    Solusi: Pakai kontrol dari kelompok Form Controls di menu Insert yang sama bila tersedia, lalu hubungkan ke macro lewat Assign Macro. Atau jalankan macro dari Developer lalu Macros.

  • Data baru menimpa isian yang sudah ada

    Penyebab: Kode memakai nomor baris yang tetap, jadi setiap isian ditulis ke baris yang sama.

    Solusi: Cari baris kosong berikutnya dengan End(xlUp) seperti pada kode di atas, bukan menulis nomor baris sendiri.

  • Tombol tidak jalan setelah file dikirim ke orang lain

    Penyebab: File disimpan sebagai .xlsx sehingga kodenya hilang, atau penerima belum mengizinkan macro.

    Solusi: Simpan sebagai .xlsm. Minta penerima klik Enable Content setelah memastikan file itu dapat dipercaya.

Jangan tertukar

Tombol ActiveX sering dibandingkan dengan tombol Form Control, padahal cara kerjanya berbeda. Tombol ActiveX punya kode klik sendiri di lembar, bisa diatur lewat Properties, dan butuh Design Mode untuk diedit. Tombol Form Control lebih sederhana: kamu tinggal memilih macro yang sudah ada lewat Assign Macro. Pilih ActiveX bila ingin kontrol penuh di Windows, dan Form Control bila cukup menjalankan satu macro.

Tanya jawab

Bagaimana memunculkan UserForm saat tombol di lembar diklik?

Di kode klik tombol, tulis satu baris UserForm1.Show. Nama UserForm1 adalah nama bawaan formulir pertama, jadi sesuaikan kalau kamu menggantinya. Saat tombol diklik, formulir tampil di atas lembar kerja. Untuk mencoba formulir tanpa tombol, kamu bisa memilihnya di editor VBA lalu menekan F5.

Bagaimana mengubah tulisan pada tombol yang sudah dibuat?

Aktifkan Design Mode di tab Developer, lalu klik tombolnya sekali untuk memilih. Buka jendela Properties dari tab yang sama, cari baris Caption, dan ganti isinya. Setelah selesai, matikan Design Mode supaya tombol bisa diklik. Kalau kamu klik ganda saat Design Mode aktif, yang terbuka adalah editor kodenya.

Bagaimana kursor kembali ke TextBox setelah data disimpan?

Tambahkan TextBox1.SetFocus setelah baris yang mengosongkan isiannya. Dengan begitu kursor langsung berada di kotak isian, dan petugas bisa mengetik data berikutnya tanpa mengklik lagi. Cara ini berguna kalau kamu mencatat banyak data berturut-turut dalam satu sesi memakai formulir yang sama.

Ringkasan

Command Button menjalankan macro saat diklik, dan UserForm menyediakan formulir isian yang rapi. Matikan Design Mode agar tombol bisa diklik, simpan sebagai .xlsm, dan cari baris kosong dengan End(xlUp) supaya data tidak tertimpa.
